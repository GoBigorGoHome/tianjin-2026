# 箱根驿传

箱根驿传接力赛跑的路程有 $10$ 段，有 $9$ 个接力点。有 $n$ 个队伍参加，没有两个队伍同时到达终点或同时到达同一个接力点。

已知每个队伍到达终点的用时排名，和此排名相比于到达最后一个接力点的用时排名的变化情况（上升，下降，不变）。

按照队伍最终排名从高到低的顺序给出每个队伍的排名变化情况，求到达最后一个接力点的用时排名有多少种可能，模 $10^9+7$。


- $1 \le n \le 200$

# 消消乐

我们称一个字符串是**可消除的**，如果可对它进行下述操作若干次，使它成为一个空串：
- 删除字符串中某两个相邻且相同的字符，把剩余字符拼接在一起。

给你一个长为 $N$ 的由小写字母构成的字符串 $S$，求 $S$ 有多少个非空子串是可消除的。

- $1 \le N \le 2 \times 10^6$ 

---

<div class=definition>

称字符串 $S$ **可分解**，若存在可消除的非空字符串 $X, Y$ 使得 $S = X + Y$。

</div>

---


<div class=proposition>

设 $A, B$ 是非空字符串。若 $A+B$ 可消除且 $B$ 可消除，那么 $A$ 可消除。

</div>

<div class=proof>


</div>

---

我们尝试对可消除序列进行**分解**。

若序列 $A, B$ 都是可消除的，那么 $A + B$ 也是可消除的，$+$ 表示序列的拼接。

反过来，如果 $A + B$ 是可消除的，$B$ 是可消除的，那么 $A$ 也是可消除的。

于是我们可以把一个可消除序列分解成若干不可分解的可消除序列。

例如 `accabccb` = `acca` + `bccb`。

---

对于一个序列 $A=(A_1, \dots, A_n)$，我们考虑它的**最短可消除后缀**。
我们找到一个最大的正整数 $i$ 满足 $1 \le i \le n$ 且 $(A_i, \dots, A_n)$  是可消除的。
如果这样的 $i$ 的存在，那么就用下标 $i$ 来表示 $A$ 的最短可消除后缀。

例如 
- (1, 2, 3, 3, 2) 的最短可消除后缀是 (2, 3, 3, 2)，我们用下标 $2$ 来表示。
- (1, 0, 0, 1, 0) 没有可消除后缀。

---

对于 $S$ 的每个前缀 $S[1..i]$，我们计算它有多少个可消除后缀，记作 $f[i]$。
那么答案就是 $\sum_{i=1}^{N} f[i]$。

如果 $S[1..i]$ 的最短可消除后缀是 $j$，那么 $f[i] = f[j - 1] + 1$。
若 $S[1..i]$ 没有可消除后缀，那么 $f[i] = 0$。

---

现在的问题是如何找出 $S[1..i]$ 的最短可消除后缀（的起始位置）。

如果 $S[i] = S[i-1]$ 那么 $S[1..i]$ 的最短可消除后缀是 $i-1$。
否则 $S[1..i]$ 的最短可消除后缀就是满足下列条件的最大下标 $j$
- $j < i - 1$
- $S[j] = S[i]$
- $S[j+1..i-1]$ 可消除

为此，我们计算一个位置，$p[i-1][c]$，表示满足下列条件的最大整数 $j$
- $j < i - 1$
- $S[j] = c$
- $S[j+1..i-1]$ 可消除。

![h:100](最短可消除后缀.svg)

---


现在来考虑如何计算 $p[i][c]$。
假设 $S[1..i]$ 的最短可消除后缀是 $j$。
> 若 $S[1..i]$ 没有可消除后缀，$p[i][c]$ 就不存在。

如果 $S[j - 1] = c$，那么 $p[i][c] = j - 1$，

![h:80](最短可消除后缀2.drawio.svg)

否则 $p[i][c] = p[j-1][c]$。
