title: bitmask DP
---

用一个 $N$ 位的二进制数 $x$ 表示集合 $\set{0, 1, 2, \dots, N-1}$ 的一个子集 $S$。
$x$ 的二进制第 $i$ 位是 1 当且仅当 $i \in S$。

例如，用二进制数 1001 表示集合 $\set{0,3}$。

$\set{0, 1, 2, \dots, N-1}$ 的子集有 $2^{N}$ 个，它们和整数 $0, 1, \dots, 2^{N}-1$ 一一对应。

---

# 位运算

`<<`：左移 
例：`5 << 2` 结果是 20。`110` $\to$ `11000`。

`>>`：右移
例：`18 >> 2` 结果是 8。`10010` $\to$ `100`。

---

`&`：按位与
例：`18 & 6` 结果是 2。

  10010

</div>

<div class=columns>

`|`：按位或
例：`18 | 6` 结果是 22。

```
  10010
| 00110
--------
  10110
```

</div>

<div class=columns>

`^`：按位异或
例：`18 ^ 6` 结果是 20。

```
  10010
^ 00110
--------
  10100
```

</div>

# 位运算符的优先级

`a * b`，`a / b`，`a % b`
`a + b`，`a - b`
`a << b`，`a >> b`
`a < b`，`a <= b`，`a > b`，`a >= b`
`a == b`，`a != b`
`a & b`
`a ^ b`
`a | b`
`a && b`
`a || b`

# 位运算的应用

`x & 1` 结果是 x 的第 0 位上的数字，也表示 x 的奇偶性。

`(x >>) i & 1` 结果是 x 的二进制第 i 位上的数字。

`x ^ (1 << i)` 结果是把 x 的二进制第 i 位上的数字反转所得的数。

`x | (1 << i)` 结果是把 x 的第 i 位上的数字置为 1 所得的数。
